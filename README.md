# Chesterton — Gaxeta

Plataforma privada de monitoramento de gaxetas e gestão de ativos.

Acesse [a plataforma](https://laboratoriochesterton.github.io/sensorgaxeta/) com sua conta autorizada. O [manual de operação](https://laboratoriochesterton.github.io/sensorgaxeta/operacao.html) descreve a organização de ativos, o vínculo dos sensores e a consulta de telemetria.

Este diretório contém o pacote estático de produção. O aplicativo Android é distribuído diretamente pela equipe. Credenciais da placa e chaves administrativas não fazem parte desta publicação.
