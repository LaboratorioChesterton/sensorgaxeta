# Gaxeta Gestão de Ativos — Chesterton

Plataforma privada de monitoramento de gaxetas e gestão de ativos.

Acesse [a plataforma](https://laboratoriochesterton.github.io/sensorgaxeta/) com sua conta autorizada. O [manual de operação](https://laboratoriochesterton.github.io/sensorgaxeta/operacao.html) descreve a entrada, a árvore de ativos, o vínculo dos sensores, a telemetria e a administração de usuários.

Os arquivos na raiz deste repositório são o pacote estático servido pelo GitHub Pages. A fonte editável está em `frontend/` (veja `frontend/README.md`) e as migrações do banco em `supabase/`. O aplicativo Android é distribuído diretamente pela equipe, por arquivo APK. Credenciais da placa e chaves administrativas não fazem parte desta publicação.
